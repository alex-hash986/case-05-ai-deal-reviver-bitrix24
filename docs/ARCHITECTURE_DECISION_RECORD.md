# ADR-001. Модульный каркас ai-business-core

Статус принят для Фазы 1.

Ядро наследует из Кейса №2 OpenAI-совместимый шлюз, предавторизацию бюджета
и модель SQLite WAL. Домен владеет DTO, расчётами, проверкой текста,
сборкой предложения и портом CRM. Входная точка FastAPI связывает
зависимости. Streamlit вызывает API и читает результаты с локального диска.

Структура src/core, src/domain, src/integrations, src/api и src/ui
соответствует оговорённым путям Фазы 1. Входные контракты сметы и звонка
объединяются в DealContextInput без импорта других кейсов.

SQLite и один процесс-публикатор обслуживают локальный пилот.
Блокировка файла ограничивает число публикаторов на базу. После прерывания
цикл с контрольной точкой становится доступным для сверки, а незавершённую
генерацию можно повторить. Мок-адаптер хранит устойчивый журнал операций.
В Фазе 2 HTTPS REST изолирован в адаптере порта CRM. После обрыва он сверяет
удалённое состояние по идентификатору или устойчивому маркеру. Комментарий
и вложение создаются одним REST-вызовом. Для MCP интеграции достаточно
реализовать тот же порт с семантикой сверки.
