От курсора до задачи менеджеру

Отбор

SQLite WAL хранит курсор «дата изменения + ID». SLA стадии, будущие дела, cooldown и отказ клиента определяют, какие карточки пропускать.

Оценка и черновик

Decimal-скоринг считает риск и прогноз. LLM формирует касание, а CommercialPolicyGuard проверяет обещания. При нехватке данных требуется ручной разбор.

Подтверждение и сверка

API проверяет токен и полномочия. После одобрения менеджер получает задачу в CRM. После неоднозначного ответа reconcile сверяет квитанции в bitrix_steps.
